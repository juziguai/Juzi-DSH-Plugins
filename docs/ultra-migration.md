# Ultra 内置角标迁移

Ultra 0.2.2 将模型菜单、推理强度滑块、动效与版本角标合为一个插件，沿用 `@juzi/dsh-ultra-effort` 包名。搜索插件独立维护。版本表由更新脚本生成，运行时不联网查询。

## 现有安装

1. 记录当前 Ultra 与角标版本，保留已有 profile 备份。
2. 刷新「插件 → 发现」，点击 **Ultra Effort 名称**进入市场详情，在版本列表安装 **0.2.2**。右侧“有新版本”按钮只打开已安装详情。
3. 确认 Ultra 显示 0.2.2 并启用。检查 Flash `1017`、Pro `0813` 与悬停完整快照名；切换模型、调整强度，并检查最高档粒子及退出动效。
4. 验收通过后停用独立 **Model Version Badge**。再次检查角标仍存在；随后可按需卸载旧包。

升级期间旧角标仍启用也可共存：它只装饰官方标签槽，Ultra 直接渲染内置组件，不注册旧的自定义标签槽。停用或卸载旧角标不会关闭 Ultra 的内置角标。新用户仅安装 Ultra 即可。

这些步骤由安装者在客户端执行，仓库构建不会修改已安装 profile、停用插件或重启应用。若宿主提示重启，按客户端提示执行后再验收。

## 回退

若新版未通过验收，保留错误现场，重新安装已验收的 **Ultra 0.1.2 + Model Version Badge 0.1.1** 并启用两者。可临时添加下面的历史索引，在对应插件名称下选择旧版本：

```text
https://raw.githubusercontent.com/juziguai/Juzi-DSH-Plugins/e941dae0fb1fa86834446186214b798548cece6d/marketplace/index.json
```

历史索引固定安装到当时的源码，不依赖当前分支。回退只涉及两个界面插件；会话、模型配置与搜索凭证无需改动。
