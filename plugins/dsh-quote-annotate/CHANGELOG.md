# 更新记录

## [0.1.0] - 2026-10-28

### 新增

- 独立的文本引用与评论：选区气泡、官方引用 chip、悬停预览和 dock 编辑删除。
- 按会话持久化、跨窗口合并、截断与转义；遵循官方提交与失败恢复流程。
- 使用 DSH 设计 token，支持浅色/深色、键盘与减少动态效果设置。
- 评论使用胶囊输入框与圆形确认按钮，焦点转入输入框后保留选区高亮和引用编号；不包含麦克风。
- 打磨列表独立省略、来源 chip 评论标记、实底预览分层、正文行盒避让和整行细滚动条。
- 通过官方用户文本规则与 keyed 插槽折叠已发送引用；保留模型原始负载，停用恢复原生展示。

### 修复

- 评论输入区四周保留8px内边距，内部保持六整行滚动，不截出半行文字；浮层与选区标记随滚动和窗口尺寸同步定位。
